Перевод с экрана

Выберите область экрана. Windows OCR распознает текст, а Luma покажет перевод в отдельном оверлее.

Ctrl + Alt + F8
Aa

Работа с выделением

Выделите русскую фразу и замените её английским переводом с помощью горячей клавиши.

Ctrl + Alt + F11
⌘

Локальная модель

Перевод выполняется через Ollama на компьютере. Для работы нужна установленная модель, например Qwen 2.5.

Windows 10 / 11 · x64
Что нужно знать перед использованием +

Нужны запущенная Ollama, загруженная модель и английский компонент Windows OCR. Горячие клавиши можно изменить в настройках приложения.

Автоперевод при наборе зависит от Windows UI Automation. В проверенной конфигурации Chrome этот режим не работает. Совместимость с другими браузерами, играми, несколькими мониторами и эксклюзивным полноэкранным режимом не подтверждена.

Исходный код Luma хранится в приватном репозитории. Ссылка ниже откроется только при наличии доступа.

Возможности и ограничения +

AI-чат, ручной выбор таблиц, альтернативные пути JOIN, каталог полей и скачиваемая JSON-диагностика. Приложение работает локально без подключения к PostgreSQL и не генерирует исполняемый SQL.

Связи проверяются по загруженным метаданным. Бизнес-смысл полей и выбранного маршрута требует проверки; отсутствующие в каталоге связи не добавляются автоматически.

Исходный код и инструкция по запуску доступны в репозитории PostgreSQL Navigator на GitHub.
